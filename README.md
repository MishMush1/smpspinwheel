
# Chat Wheel Weighted (Fabric 1.21.10)
Listens to chat for payments and spins an in-game weighted wheel.
Each player's slice is at least 1/10 of the target total.
Target total can be changed in-game via the GUI.

## Build
- Install Java 17 and Gradle
- Run `./gradlew build`
- Mod jar will be in `build/libs`
